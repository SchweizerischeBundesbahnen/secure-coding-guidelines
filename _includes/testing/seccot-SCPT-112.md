<!-- markdownlint-disable MD041 -->{% if include.header and include.header == true %}**SCPT-112: Testing - minimize attack surface**{% endif %}

Testing attack surface minimization is carried out in two steps:

- Step 1: document and review what has been removed or disabled in the application or system.

- Step 2: verify that the removal or disabling of these components has been effective in reducing the attack surface.

This verification can be done during code review, and by using automated tests or tools to scan the application or system for any remaining components that should have been removed or disabled.
