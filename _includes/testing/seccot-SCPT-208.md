<!-- markdownlint-disable MD041 -->{% if include.header and include.header == true %}**SCPT-208: Testing - use Content Security Policy (CSP)**{% endif %}

Testing the usage of Content Security Policy ([CSP](/terminology.html#csp-content-security-policy)) can be performed manually by code review.
Testing of CSP violations can also be performed through automatically reporting, either via the reporter feature or by collecting violation messages from e.g. headless test browsers.
