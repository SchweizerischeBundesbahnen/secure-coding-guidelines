<!-- markdownlint-disable MD041 -->{% if include.header and include.header == true %}**SCPT-01: Testing - access controls for PII data**{% endif %}

To test access controls for Personally Identifiable Information (PII) data, the following aspects can be verified:

- Verify that non-authorized personnel do not have access to PII data by attempting to access the data with an account lacking the necessary permissions.

- Verify that authorized personnel can access PII data by attempting to access the data with an account that has the necessary permissions.
