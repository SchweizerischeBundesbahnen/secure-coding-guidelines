<!-- markdownlint-disable MD041 -->{% if include.header and include.header == true %}**SCPT-104: Testing - defense in depth**{% endif %}

It is not possible to automate the testing the principle of defense in depth.
This principle must be ensured during code review.
It must be ensured that project management have allocated sufficient resources to implement multiple layers of security controls, and that sufficient tooling is made available to developers and testers to implement and verify these controls.
