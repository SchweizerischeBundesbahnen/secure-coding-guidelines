{% if include.tier and include.tier == true %}<!-- markdownlint-disable MD041 -->![MUST](https://img.shields.io/badge/MUST-ff0000.svg) {% endif %} **SCP-10: Document integrated services**

Comprehensive documentation of all integrated services ensures clarity on interfaces, data flows, and dependencies.
To meet this requirement:

- Maintain up-to-date documentation for each service and API, detailing purpose, endpoints, parameters, and data exchanges.

- Describe service dependencies, authentication mechanisms, and error-handling behaviors.

- Store the documentation in a centralized place where each team member can access.
