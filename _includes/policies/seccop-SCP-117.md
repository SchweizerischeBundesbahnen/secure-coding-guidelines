{% if include.tier and include.tier == true %}<!-- markdownlint-disable MD041 -->![SHOULD](https://img.shields.io/badge/SHOULD-ffcc00.svg) {% endif %} **SCP-117: Regularly check SonarQube security issues**

SonarQube analyzes code quality and identifies security vulnerabilities automatically.
Regularly review and fix all security issues reported by SonarQube to maintain code security standards and comply with coding conventions.

Integrate SonarQube analysis into your development workflow to catch security issues early in the development process.
Address security-related findings promptly to prevent potential vulnerabilities from reaching production.
