{% if include.tier and include.tier == true %}<!-- markdownlint-disable MD041 -->![MUST](https://img.shields.io/badge/MUST-ff0000.svg) {% endif %} **SCP-22: Perform logging of relevant information**

Logging is a fundamental requirement to be able to perform incident detection, trigger incident response, and perform security forensics.
Information must be logged according to the logging policies of your organization.
These policies define how and what must be logged.
