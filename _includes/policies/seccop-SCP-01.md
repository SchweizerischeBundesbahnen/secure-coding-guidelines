{% if include.tier and include.tier == true %}<!-- markdownlint-disable MD041 -->![MUST](https://img.shields.io/badge/MUST-ff0000.svg) {% endif %} **SCP-01: Access controls for PII data**

Personally Identifiable Information (PII) data should be protected with strict access controls to limit who can view or process it.
For this, technical measures must be implemented to control the access to PII data.
Use organizational and technical measures to ensure that only authorized personnel have access to PII data, and that access is granted based on the principle of least privilege.
