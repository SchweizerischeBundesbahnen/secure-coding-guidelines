{% if include.tier and include.tier == true %}<!-- markdownlint-disable MD041 -->![SHOULD](https://img.shields.io/badge/SHOULD-ffcc00.svg) {% endif %} **SCP-110: Implement security tests in your CI/CD pipeline**

Integrate automated security testing tools into your continuous integration and deployment pipeline to catch security issues early in the development lifecycle.
This includes static analysis, dependency scanning, and automated security test execution.

Configure pipeline gates that prevent deployment of code with critical security issues.
Automated security testing provides continuous feedback to developers and ensures security standards are maintained throughout the development process.
