{% if include.tier and include.tier == true %}<!-- markdownlint-disable MD041 -->![SHOULD](https://img.shields.io/badge/SHOULD-ffcc00.svg) {% endif %} **SCP-113: minimize PII data collection**

It is unavoidable that developed applications will process Personally Identifiable Information (PII) data.
However, due to regulatory restrictions, it is important ensure that the amount of PII data that is stored in the system is minimized.
When storing this type of data, technical measures such as encryption, and anonymization must be implemented to be compliant with relevant security standards and regulations.
